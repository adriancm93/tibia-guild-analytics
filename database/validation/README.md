# Database Validation Queries

This folder contains SQL validation queries used to inspect data quality, pipeline behavior, and API readiness.

Validation checks may include:

- Snapshot counts
- Guild/member row counts
- Latest snapshot freshness
- Cache table freshness
- API view row counts
- Join/leave/rank-change sanity checks
- Per-guild refresh status checks

These files are intended for manual verification and operational troubleshooting.
